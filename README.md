# Project: Where U.S. Tech Firms Can Lease Smart

An interactive data analysis project that identifies the best U.S. office markets for tech companies in the post-COVID era. We evaluated markets based on office affordability, availability, and leasing flexibility, while considering the different space needs of startups, scaleups, and large enterprises adapting to hybrid and remote work.


Tech: NumPy, Pandas, Matplotlib, Scikit-learn, Plotly, Geopy
